# **Projeto: A Economia do Futuro**

## **Introdução**

Este projeto é uma plataforma web informativa, desenvolvida para dar visibilidade ao **Objetivo de Desenvolvimento Sustentável (ODS) 8 da ONU**, que foca em "Trabalho Digno e Crescimento Econômico". Criado por um grupo de estudantes da **Faculdade UniNassau**, o site traduz dados complexos em uma experiência digital simples e direta.

---

## **Qual o Objetivo do Projeto?**

Nosso objetivo é **educar e inspirar**. Queremos mostrar que o trabalho digno é a base para um futuro mais justo e próspero. A aplicação serve como uma ferramenta para:

* **Conscientizar:** Apresentar de forma clara os desafios e o progresso do ODS 8.
* **Engajar:** Incentivar as pessoas a agirem e a se sentirem parte da solução.
* **Demonstrar habilidades:** Exibir nossas competências em desenvolvimento web, desde o design até a organização do código.

---

## **O Problema que Resolvemos**

Percebemos que, apesar da importância do tema, há uma grande falta de informação e engajamento prático. Muitas pessoas não sabem como suas ações se conectam com a causa global.

Nossa solução foi criar uma plataforma que:
* **Simplifica:** Transforma relatórios técnicos em conteúdo acessível.
* **Conecta:** Mostra a relação entre a dignidade no trabalho e o cotidiano das pessoas.
* **Impulsiona a Ação:** Oferece propostas concretas para que o usuário possa ajudar.

---

## **Como a Aplicação Funciona?**

A aplicação é um site de conteúdo estático, construído com tecnologias front-end.

* **Estrutura:** O projeto é modular, com HTMLs, CSS e imagens em pastas separadas. Isso garante um código limpo e fácil de gerenciar.
* **Design:** O visual, em tons de azul e branco, foi totalmente desenvolvido com **CSS puro**. A interface é clean e otimizada para ser **responsiva**, funcionando bem em qualquer dispositivo.
* **Funcionalidades:** A única funcionalidade dinâmica é o **formulário de contato**, que utiliza **JavaScript** para validar e enviar as informações, proporcionando uma interação fluida ao usuário.

### **Tecnologias Utilizadas**

* **HTML:** Estrutura e conteúdo da página.
* **CSS:** Estilização e responsividade do site.
* **JavaScript:** Lógica de interatividade (formulário).
* **Bootstrap Icons:** Biblioteca de ícones para o menu e seções.
